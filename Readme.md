## ✨ Overview

**AccessIQ** is a modern, human-friendly accessibility audit dashboard designed to help teams evaluate WCAG 2.2 compliance.  

It combines a beautiful dark UI with practical accessibility engineering features:

- Animated WCAG score ring
- Issue severity distribution
- Live trend charts
- Detailed violations with remediation
- Manual testing notes
- One-click downloadable reports

Built as a portfolio project for **Web Accessibility Engineer** roles.

---

## 🔥 Features

| Feature | Description |
|---------|-------------|
| 🎯 **WCAG Score Ring** | Animated circular progress showing overall accessibility score |
| 📊 **Trends Chart** | Historical view of Critical / Serious / Moderate issues |
| ⚠️ **Issue Distribution** | Critical, Serious, Moderate & Best Practices counts |
| 🔍 **Start Scan** | Simulates full audit → updates score + shows real violations |
| 🛠️ **Violations + Remediation** | Each issue comes with severity badge, selector & fix suggestion |
| ⌨️ **Manual Testing Notes** | Keyboard + Screen reader notes with local save |
| 📄 **Download Report** | Full JSON report with score, issues, notes & recommendations |
| 🔄 **Previous vs Current** | Clear comparison after every scan |
| 🌙 **Dark Human UI** | Soft, modern, accessibility-focused design |

## 🛠️ Tech Stack

- **HTML5** – Semantic structure
- **CSS3** – Custom dark theme, gradients, animations
- **Vanilla JavaScript** – All interactivity
- **Chart.js** – Accessibility trends visualization

No frameworks. Clean and lightweight.
